# Linux Performance Monitor Script

A shell script to monitor basic server performance stats like CPU, Memory, Disk Usage, and top processes.

## How to Run the Project

1.  **Save the Script:**
    Save the code into a file named `server-stats.sh`.

2.  **Make it Executable:**
    Open your terminal and run the following command to give the script execution permissions:
    ```sh
    chmod +x server-stats.sh
    ```

3.  **Run the Script:**
    Execute the script from your terminal:
    ```sh
    ./server-stats.sh
    ```
